the source language; every other file is a translation of `en.toml`.

## How it works

- Strings are looked up by key with `tr("menu.file.open")` and
  `trf("status.exported", &[("path", p)])`. Keys are dotted paths:
  `menu.*`, `context.*`, `tool.*`, `toolbar.*`, `docker.*`, `dialog.*`,
  `options.*`, `status.*`, `hint.*`, `fill.*`, `transparency.*`, `kind.*`,
  `welcome.*`, `doc.*`. About 3,230 keys per language.
- Files are flat `key = "value"` TOML, embedded in the binary with
  `include_str!`; a test (`i18n::tests::every_language_covers_english_keys`)
  fails the build when a language misses a key. The desktop program
  embeds all of them (`i18n::tests::the_desktop_builds_every_language_in`);
  the browser build embeds English only and fetches the chosen
  language's file from the page's `lang/` folder, showing English until
  it arrives (`docs/behavior/web.md`).
- Missing keys fall back to English at run time.
- Placeholders use `{name}`.
- Shortcuts are not translated; they are rendered from the key binding.
- The language is chosen in Options > Global > General, Language (System
  language or one of the languages), and applies without restart. Until
  one is chosen, TraceDraw starts in the language picked in the Windows
  installer, else the system's (closest supported language; Taiwan, Hong
  Kong and Macau or the Hant script choose Traditional Chinese), else
  English: see `docs/behavior/language.md`.
  Default names of new documents, pages and layers follow the language.
- Right-to-left (Arabic) moves the panel column to the left side; text
  in menus and panels is shaped by the font. The canvas and rulers do
  not flip.
- Fonts: the bundled UI font covers Latin, Greek and Cyrillic. At start-up
  the app registers system fonts as fallbacks per script (Noto Sans
  Arabic / Segoe UI / DejaVu Sans; Noto Sans Hebrew / Arial Hebrew /
  Segoe UI / DejaVu Sans for names typed in Hebrew; Noto Sans Devanagari / Nirmala UI;
  Noto Sans Bengali; Noto Sans CJK SC and JP / Microsoft YaHei / Meiryo /
  PingFang; Noto Sans CJK TC / Microsoft JhengHei / PingFang TC for Traditional Chinese; Noto Sans Lao / Lao Sangam MN / Leelawadee UI / Saysettha OT for Lao; Noto Sans Thai / Leelawadee UI / Tahoma / Thonburi / Loma for names typed in Thai) so every language renders without tofu on Windows, macOS and
  common Linux installs. `theme::UI_SCRIPT_FONTS` has the lists.

## Rules

- No user-visible literal strings in `apps/`, except unit abbreviations,
  file-format names, paper sizes and proper nouns.
- Add the English key first, then all eighteen translations in the same
  commit. Machine translation is acceptable for a first pass; mark the
  line with `# mt` so native review can find it.
- Terminology follows the localised versions of mainstream graphics
  software for each language (for example: Soldar / Souder / Verschmelzen /
  焊接 for Weld; Silueta / Projection / Kontur / 轮廓图 for Contour).
