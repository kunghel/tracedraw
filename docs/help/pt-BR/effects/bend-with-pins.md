# Dobrar com alfinetes

> *Tradução automática: esta página pode estar atrasada em relação à versão em inglês.*

Dobrar com alfinetes dobra objetos como se fossem uma folha de borracha presa
em alguns pontos. Espete alfinetes nos objetos, arraste-os, e os objetos
seguem: um alfinete move-os, dois rodam-nos, mais dobram-nos. Perto de cada
alfinete uma parte mantém a forma e só roda, por isso braços, caudas, fitas e
letras dobram com naturalidade.

## Dobrar objetos {#bend}

1. Selecione os objetos (curvas, formas, texto ou grupos; não bitmaps).
2. Escolha [[menu.effects > menu.effects.bend_pins]] para abrir [[pins.title]].
3. Clique nos objetos na pré-visualização para espetar alfinetes: um onde uma
   parte deve ficar, um em cada parte a mover.
4. Arraste um alfinete para o novo lugar. A pré-visualização mostra os
   objetos como eram a cinzento e dobrados a azul. Clique com o botão direito
   num alfinete para o tirar; [[pins.clear]] tira todos.
5. Clique em OK.

Os objetos passam a curvas (com o envelope, a perspetiva e a distorção
incorporados) e dobram, num só passo de desfazer. Cada lado é cortado em
curvas curtas antes, por isso um lado longo e reto dobra suavemente.

## Até onde um alfinete segura {#reach}

[[pins.reach]] define a rapidez com que a força de um alfinete diminui com a
distância. Valores baixos espalham a dobra pelo objeto todo; valores altos
mantêm cada parte perto do alfinete mais próximo, com a dobra entre os
alfinetes.
