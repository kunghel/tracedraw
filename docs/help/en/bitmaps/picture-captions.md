# Picture captions

[[menu.bitmaps > menu.bitmaps.captions]] writes each picture's name beside
it, in one step: below, above, to the left or to the right of the picture,
a set gap away. It suits recipe pages, catalogues and charts with many
pictures, where each picture needs its label.

The name is the one the picture came in with, the name of the file it was
imported from, or the name you gave it in the Objects docker. A picture
without a name gets no caption, and the status bar says how many were
left out.

## To add captions {#add}

1. Select the pictures to caption. With nothing selected, every picture on
   the page gets a caption.
2. Click [[menu.bitmaps > menu.bitmaps.captions]].
3. Choose the side under [[dialog.captions_side]] and set the options
   below.
4. Click [[dialog.ok]]. All the captions come in one undo step.

## Options {#options}

- **[[dialog.captions_side]]** [[dialog.captions_below]] or
  [[dialog.captions_above]] centres the caption along the picture;
  [[dialog.captions_left]] and [[dialog.captions_right]] line it up with
  the picture's edge, half way up.
- **[[dialog.captions_gap]]** The distance between the picture's edge and
  the caption.
- **[[dialog.captions_prefix]]** and **[[dialog.captions_suffix]]** Text
  written before and after every name, such as `Fig. ` before it. To give
  one picture its own prefix, select only that picture.
- **[[dialog.captions_font]]** and **[[dialog.captions_size]]** One font
  and size for every caption.
- **[[dialog.captions_group]]** Each picture and its caption become one
  group, which moves and scales as one.

## To change the captions {#change}

Run [[menu.bitmaps > menu.bitmaps.captions]] again on the same pictures
(or on their groups) with other settings: the captions they already have
are replaced, not doubled. The settings are kept for the next time.
